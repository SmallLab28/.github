# SmallLab28 software

**High-performance document processing and translation technology.**

We are the creators and maintainers of the PrivatePDF ecosystem and custom C/C++ document libraries. From robust PDF data extraction and compression engines to specialized layout-preserving translation applications, SmallLab28 technology is built to handle complex document workflows efficiently and securely.

---

## Our Projects

### [PrivatePDF Web](https://privatepdf.tech/)
A comprehensive suite of all-in-one PDF tools. Designed for fast, secure, and precise document processing and manipulation directly within the browser ecosystem.

### [PrivatePDF App](https://privatepdf.tech/app/download/download)
A specialized application dedicated to high-quality PDF translation. Built to handle heavy, complex documents while flawlessly preserving 100% of the original layout and formatting. 

### [WinnerZ](https://github.com/SmallLab28/WinnerZ)
A stable, production-ready document extraction library written in C++. Designed to parse and extract heavy PDF data structures with absolute precision. This engine forms the core layout-preservation backbone of our translation tools. Available under the Apache License 2.0.

### [Pation](https://github.com/SmallLab28/Pation)
A highly optimized PDF compression library written in C and C++. Currently under active development, it is designed to significantly reduce file sizes while maintaining pristine document quality. Planned for release under the Apache License 2.0.
